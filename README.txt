# Chat

Простой многопользовательский чат на Go и WebSocket.

Пользователи подключаются к серверу под своим именем и могут обмениваться сообщениями в реальном времени. Сервер автоматически рассылает сообщения всем подключённым пользователям.

## Возможности

- Подключение нескольких пользователей одновременно
- Авторизация под никнеймом или в режиме `incognito`
- Обмен сообщениями в реальном времени через WebSocket
- Уведомления о подключении и выходе пользователей
- Отображение статуса WebSocket-соединения
- Очистка чата после подтверждения всех подключённых пользователей
- Счётчик непрочитанных сообщений во вкладке браузера
- Адаптивный интерфейс

## Структура проекта

chat/
├── internal/
│   ├── handlers/    # HTTP и WebSocket обработчики
│   ├── hub/        # Управление подключёнными клиентами и сообщениями
│   └── server/     # Запуск HTTP-сервера
├── web/
│   └── index.html  # Клиентская часть чата
├── main.go
├── go.mod
└── README.md

## Требования
- Go — версия указана в go.mod
- Git
- Современный браузер с поддержкой WebSocket
Запуск
Клонируйте репозиторий и перейдите в корень проекта:
```git clone <URL_РЕПОЗИТОРИЯ>
   cd chat
```

Запустите сервер:
```go run .
```

Зависимости Go будут загружены автоматически.
После запуска откройте в браузере:
http://localhost:8080/home

Для проверки работы нескольких пользователей можно открыть чат в нескольких вкладках браузера и войти под разными именами.

## Как работает чат
После подключения клиент устанавливает WebSocket-соединение с сервером:
Browser
   ↓
WebSocket
   ↓
WSHandler
   ↓
Hub
   ↓
Все подключённые пользователи

Сервер хранит список подключённых клиентов и рассылает им сообщения через Hub.
Для служебных действий используются специальные команды с префиксом CMD:.
Например:
CMD:show_confirm
CMD:confirm_yes
CMD:cleared
CMD:user_joined:<имя>
CMD:user_left:<имя>

Обычные сообщения передаются как текст и отображаются в чате.

## Очистка чата
При нажатии Clear chat сервер отправляет всем пользователям запрос на подтверждение.
Чат очищается только после того, как подтверждение отправят все подключённые пользователи.
Остановка
Для остановки сервера нажмите:
Ctrl+C

## Если что-то не работает
Порт 8080 занят
Закройте программу, которая использует порт 8080, или измените порт запуска сервера.
Страница не открывается
Убедитесь, что сервер запущен и используется правильный адрес:
http://localhost:8080/home

Изменения в коде не отображаются
Перезапустите сервер:
```go run .
```

и обновите страницу через:
Ctrl+F5

WebSocket не подключается
Проверьте, что сервер запущен и браузер подключается к тому же адресу, на котором работает сервер.
