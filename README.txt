# Chat

Простой чат на Go и WebSocket. Сообщения рассылаются всем подключённым пользователям в реальном времени.

## Требования

- [Go](https://go.dev/dl/) (версия указана в файле `go.mod`)
- Git

## Запуск

1. Запустите сервер (зависимости скачаются автоматически):

```bash
   go run .
```

2. Откройте в браузере:

```
   http://localhost:8080/home
```

3. Чтобы пообщаться самому с собой, откройте страницу во второй вкладке.

> Запускать нужно из корня проекта: страница чата подгружается по относительному пути `web/index.html`.

## Остановка

Нажмите `Ctrl+C` в терминале.

## Если что-то не работает

- **Порт 8080 занят:** закройте программу, которая его использует, и запустите сервер заново.
- **Страница не открывается (404):** проверьте адрес, нужен именно `/home`, а не `/`.
- **Изменения в коде не видны:** перезапустите `go run .`, а в браузере обновите страницу через `Ctrl+F5`.
