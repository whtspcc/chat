# Chat

Многопользовательский чат на Go, WebSocket и PostgreSQL.

Пользователи входят под своим именем (или в режиме `incognito`), выбирают комнату и обмениваются сообщениями в реальном времени. Все сообщения сохраняются в базе, а при входе в комнату показываются последние сообщения этой комнаты.

## Возможности

- Несколько комнат, сообщения и история изолированы по комнатам
- Вход под никнеймом или в режиме `incognito`
- Обмен сообщениями в реальном времени через WebSocket
- Сохранение сообщений в PostgreSQL и история при входе (последние 10 сообщений)
- Счётчик онлайн-пользователей комнаты
- Уведомления о входе и выходе пользователей
- Очистка чата после подтверждения всеми участниками комнаты
- Выбор комнаты через адрес: `?room=games`
- Проверка ника на сервере (длина до 20 символов, без запятой)
- Счётчик непрочитанных сообщений во вкладке браузера
- Адаптивный интерфейс

## Структура проекта
```
chat/
├── internal/
│ ├── handlers/ # HTTP и WebSocket обработчики
│ ├── hub/ # Комнаты, клиенты, рассылка сообщений
│ ├── model/ # Общие типы: Client, Message
│ ├── server/ # Запуск HTTP-сервера
│ └── store/ # Работа с PostgreSQL
├── migrations/
│ ├── 001_messages.sql # Таблица messages
│ └── 002_rooms.sql # Таблица rooms, room_id в messages
├── web/
│ └── index.html # Клиентская часть чата
├── main.go
├── go.mod
└── README.md
```

## Требования

- Go — версия указана в `go.mod`
- PostgreSQL 14 или новее
- Git
- Современный браузер с поддержкой WebSocket
